# Guiders SDK

Widget de chat y tracking para webs de clientes. Documentación: [docs/README.md](docs/README.md).

## Arrancar

Necesitas el backend en http://localhost:3000.

```bash
npm install              # primera vez
npm start                # webpack :8081 + WordPress Docker
```

- Demo webpack: http://localhost:8081
- WordPress (plugin): http://localhost:8090

Guía de producto e instalación: [docs/producto.md](docs/producto.md).
